This portfolio documents my work for Lab 05. The focus is on building a usable website from an existing template while keeping the structure of the project understandable.

### A deliberate approach to presentation

I used a restrained color palette and straightforward navigation so that the examples remain the focus. The Getting Started page intentionally departs from that consistency: its first three steps use different heading and paragraph styles to demonstrate how CSS can target a specific section without changing the rest of the page.

### Separating content from presentation

The Table Demo stores its comparison items in YAML and renders them through a Liquid layout. This separation makes the page easier to maintain because the content can change without rewriting the table. In an analytical project, the same approach could organize program characteristics, evaluation criteria, or reporting categories.

### Keeping the limits visible

The comparison uses the lab's humorous Ryan Reynolds and Ryan Gosling example. It demonstrates a publishing technique; it is not a factual assessment of either actor. A professional comparison would require defined criteria and credible evidence for each entry.

The [project repository](https://github.com/nicholasspino/lab-05-site) contains the configuration, source pages, and custom layout. The site retains credit to Beautiful Jekyll and the DS4PS teaching examples.
