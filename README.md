## Assignment requirements

| Requirement | Implementation |
| --- | --- |
| Copy the assigned template | Fork of DS4PS/beautiful-jekyll; original layouts and assets retained |
| Customize name, description, and colors | _config.yml |
| Update the landing page | index.html |
| Add Getting Started under Resources | getstarted.md and navbar-links |
| Style three sections individually | gs-section-01, gs-section-02, gs-section-03 divs with markdown="1" and scoped CSS |
| Add a Liquid layout and table page | _layouts/liquid-table.html (parent: page), table-demo.md |
| Include the comparison image | img/ryan-v-ryan.jpg |
| Add Table Demo navigation | _config.yml |

The Getting Started content is copied from the README in the assigned archive to preserve the version that matches this lab. The three setup steps are wrapped in separate divs. A note explains the project-site address used here. The table preserves the supplied sample lists, replaces placeholder prose with an explanation, and identifies the entries as humorous demonstration data.

## Publishing

In Settings → Pages, select Deploy from a branch, the default branch, and /(root). The baseurl is /lab-05-site. A repository rename requires updating that setting.
